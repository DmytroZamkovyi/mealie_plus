# Mealie Plus

Інтеграція Home Assistant для [Mealie](https://mealie.io): списки покупок, що зливаються й відмічаються в обидва боки в усіх користувачів, та необов'язкове заповнення порожнього в Mealie через ШІ (мітки, одиниці, аліаси, описи рецептів, КБЖУ, інструменти, картинки).

## Встановлення

1. HACS → ⋮ → **Користувацькі репозиторії** → додайте цей репозиторій, категорія **Integration** (або натисніть кнопку HACS вище).
2. Завантажте **Mealie Plus** і перезапустіть Home Assistant.
3. **Налаштування → Пристрої та служби → Додати інтеграцію → Mealie Plus** (або натисніть другу кнопку вище). Потрібні адреса Mealie й API-токен.
4. Створіть список справ з назвою `Mealie: <назва списку Mealie>` (наприклад `Mealie: Метро`).

## Що буде робити

- Читає кожен список покупок Mealie й записує **один об'єднаний список** у списки `todo` Home Assistant. Список із назвою `Mealie: <назва списку Mealie>` (префікс налаштовується) автоматично синхронізується з відповідним списком Mealie, у кожного користувача, хто такий створив. Списки між собою не зливаються.
- Відмітка пункту в Mealie чи в будь-якому з цих списків стає відміткою для всіх.
- Інші платформи підключаються до списку як додаткові цілі (`async_register_external_target`), а вебхук (`/api/webhook/<id>`, показується в налаштуваннях) запускає синхронізацію негайно.
- **Зливає те, що Mealie не зливає**: `1 ч. л. + 1 ст. л.` солі стає `Сіль, 20 мл`; `1 голівка + 7 зубчиків` часнику стає `13 зубчиків`; соняшникова й рослинна олія це один продукт; рядки «за смаком» збираються в один.
- **Двосторонньо**: відмітили пункт у Home Assistant, і всі пункти Mealie за ним відмічені (і навпаки). Видалили рядок, і його пункти в Mealie видаляються (із запобіжником від масового видалення).
- Текст, набраний чи надиктований у Home Assistant (`2 кг картоплі`), розбирається й потрапляє в список Mealie.
- Відмічені пункти раз на тиждень видаляються з обох боків, тож список не розростається.
- Одиниці, перетворення, синоніми й густини наближені навмисно й редагуються.
- Усе налаштовується в інтерфейсі Home Assistant. Без YAML і власних карток.

## Необов'язково: AI-збагачення Mealie

Вимкнено за замовчуванням (Налаштувати → друга сторінка). Використовує дію Home Assistant `ai_task`, тож ключ ШІ лишається в HA (наприклад, інтеграція OpenAI з дешевою моделлю). За розкладом (раз на N годин) і кнопкою заповнює **лише порожнє**, нічого не перезаписує:

- мітки й аліаси для продуктів, у яких їх немає; одиниці для відкритих пунктів списку без одиниці;
- для рецептів: опис, порожні поля КБЖУ, інструменти й картинку, згенеровану через `ai_task`.

Відповіді перевіряються (мітки й одиниці мають уже існувати в Mealie, аліаси не мають збігатися з іншими продуктами). Витрати обмежені лімітами «об'єктів за запуск» і «картинок за запуск», і те саме двічі протягом 14 днів не запитується.
